# Changelog

## v1.2.0 — 2026-09-16

### Added
- Enhanced vCard fields: multiple phone numbers (mobile/work/fax), multiple URLs (website/social), organization with department and sub-department, nickname, birthday, and notes
- Nextcloud 35 compatibility

---

## v1.1.2 — 2026-08-07

### Fixed
- Logo now scales to preserve aspect ratio instead of stretching to fill the reserved box (non-square logos no longer render distorted)
- Logo backfill box now uses the QR code's background color instead of a hardcoded white, so it blends correctly with non-white backgrounds

---

## v1.1.1 — 2026-08-02

### Added
- Saved styles: create, edit, and reuse QR code style presets (colors, logo)
- Logo embedding: overlay a logo from Nextcloud Files onto QR codes
- Folders: organize library entries into folders
- Recently Deleted panel with restore and empty-trash for library items and styles

### Fixed
- App icon rendering in dark mode
- Code integrity signing process

---

## v1.0.2 — 2026-07-16

### Added
- German (de) localization developed in conjunction with Stadt Rastatt, Rastatt, Germany
- Nextcloud 34 compatibility

### Changed
- All user-facing strings now support i18n/l10n for future language additions
